# 0.19.0-alpha.1 — developer preview

EiZ Workbench is offered as an adaptable Windows codebase for companies and GTM engineers. It combines local product/contact data, Gmail workflows and configurable model providers. Companies can inspect the implementation and adapt it with their developers or Work.

This first public-source candidate derives from pilot.7. It adds an MIT license, generic examples, a standalone build/verification path, dependency notices and developer documentation. It does not add product features. Private development history, profiles, customer material, credentials and old artifacts are excluded from the source export.

Start with README.md, then docs/BUILD.md and docs/ADAPTING-WITH-WORK.md. Exact checks and remaining gaps are listed in docs/VALIDATION.md and docs/LIMITATIONS.md.

## Suitable for

- Developers and GTM engineers evaluating or adapting a local workflow foundation.
- Technically supported teams in companies of any size, including enterprise departments, with their own Google OAuth setup and model-provider accounts; no enterprise-wide readiness claim.
- Controlled trials with synthetic data before connecting authorized test accounts.

## Not yet established

- Turnkey onboarding for nontechnical users, central Google production approval or external-user acceptance.
- Live Gmail/model end-to-end acceptance for this release.
- Shared team CRM operation, unattended cloud availability or an Outlook integration.

The Windows installer is unsigned. API usage and optional relay hosting are not included. This release is a developer alpha for evaluation and adaptation; review the documented validation gaps before using business data.
